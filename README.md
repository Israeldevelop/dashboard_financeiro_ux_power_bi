# Dashboard Financeiro — UX e Navegação

## 📊 Sobre o projeto

Projeto desenvolvido em Power BI a partir de um relatório financeiro, com foco na **experiência do usuário (UX)**, organização visual, interatividade e navegação entre páginas.

O desafio teve como objetivo atualizar o relatório financeiro original, aplicando conceitos de posicionamento, contraste, proporção visual, segmentação dos dados e navegação intuitiva.

## 🎯 Objetivo

Transformar o relatório financeiro inicial em uma solução mais clara, interativa e agradável para análise dos dados, facilitando a exploração das informações pelo usuário.

## 🛠️ Tecnologias utilizadas

- **Power BI**
- **Power Query**
- **DAX**
- Modelagem de dados
- Bookmarks
- Botões de navegação
- Segmentações de dados
- Matrizes e gráficos interativos

## 📄 Estrutura do relatório

O projeto possui quatro páginas principais:

- **Home page** — página inicial e acesso à navegação.
- **Sales** — análise de vendas, período, segmentos e produtos.
- **Profit** — análise de lucratividade e composição dos resultados.
- **Report** — visão complementar dos dados.

## ✨ Principais melhorias

- Reorganização dos elementos com foco em hierarquia visual.
- Ajustes de posicionamento e proporção dos visuais.
- Melhorias de contraste e estilização.
- Criação e ajuste de segmentações de dados.
- Modificação do gráfico de área de vendas por período.
- Criação de matriz para descrição das vendas.
- Implementação de bookmarks para alternar entre análises.
- Navegação entre páginas por meio de botões.
- Criação de menus de navegabilidade.
- Aplicação de estados de foco e seleção nos botões.
- Padronização visual entre as páginas do relatório.

## 🧭 Experiência do usuário

A navegação foi construída para permitir que o usuário explore o relatório de forma mais intuitiva, utilizando menus, botões e interações entre os visuais.

O projeto também considera princípios de **posicionamento, contraste, proporção visual e segmentação dos dados**, sem tratá-los como regras rígidas, buscando equilíbrio entre usabilidade e criatividade.
